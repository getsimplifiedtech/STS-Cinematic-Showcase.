Settings for vercel: SYNTHETIC STAGING INSTRUCTIONS. This bundle holds no credential, account, project or team identifier and cannot deploy anything.

* Framework Preset: Other (vercel.json also sets "framework": null). Build Command and Install Command: blank (VC-13). No environment variables.
* Root Directory / Output Directory: Root Directory: the bundle root, where vercel.json sits (whether vercel.json must sit at the project root when a Root Directory is set was not established: HR-06). Output Directory: site (also in vercel.json).
* Deployment Protection: Decide deliberately and record it. Whether previews are protected by default was reported inconsistently by the documentation results (HR-14), so this bundle does not rely on it. Making a preview publicly reachable is a conscious setting change with its own approval (D-P3-5). Keep X-Robots-Tag: noindex (VC-16).
* Custom domain: The client domain, at its root (D-P3-2); www to apex is a domain setting, not a rewrite.
* Strict-Transport-Security: The platform default for a custom domain is max-age=63072000 without includeSubDomains; *.vercel.app domains additionally get includeSubDomains; preload from the platform whatever vercel.json says, so the never-preload rule cannot apply there (VC-15). vercel.json sets the policy value for a custom domain; read the live header to see which one wins (unverified).
