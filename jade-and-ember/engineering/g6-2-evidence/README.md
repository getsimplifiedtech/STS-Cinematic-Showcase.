# G6-2 evidence

Everything here comes from the synthetic release dry run (`npm run check:release-dryrun`): the real release tool, parser and git, in a throwaway copy, with invented personas and fixtures that say so. Nothing here is an approval, evidence or a decision of a person, and no real record, reviewer or ledger row was created or changed.

* `before-after.md`: the findings measured at the G6-1 base and on the G6-2 tree
* `negative-tests.md`: every scenario of the final run (rejection, revocation, forged and incomplete evidence, record placement, ZIP container, package, channel), expected and observed
* `dry-run-before.json`, `dry-run-after.json`: the raw reports of the two runs
