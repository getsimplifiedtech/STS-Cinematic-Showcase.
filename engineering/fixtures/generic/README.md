# Quillfeather Letterpress (generic fixture)

An invented letterpress studio that the STS engineering uses to prove it runs its whole verification pipeline on a website that is not any client. It is a demonstration (`noindex, nofollow`), has no client and is never released.

The creative authority is the official Anthropic `frontend-design` skill, pinned by hash in `engineering/authority.json`; the fixture's appearance is a test sample, not a design. STS engineering governs everything else.

Run it: `cd engineering && npm ci --ignore-scripts && npm run verify` (the default project of the framework's scripts is this fixture).
